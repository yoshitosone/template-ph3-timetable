# API の約束

画面（front/）と API（api/）のあいだで決めたことを、エンドポイントごとに書いておく場所です。
作り始める前に書いて commit し、作りながら変えたら、このファイルも同じ commit で直します。

1つの要望につき1つのファイルにします（例：`reviews.md`）。形は下の見本と同じにします。

## 見本：授業の登録と更新（W8・W10）

### エンドポイント

| メソッドと URL | だれが | 送るもの | 返るもの（成功） | 失敗のとき |
|---|---|---|---|---|
| `POST /api/courses` | 教務課の職員（`is_admin` が真） | 授業の8つの値（下の「送る JSON」） | 201。`{ "data": 授業 }`（`id` を含む9つの値） | ログインしていない 401／職員でない 403／値が決まりに合わない 422 |
| `PATCH /api/courses/{course}` | 教務課の職員 | 授業の8つの値 | 200。`{ "data": 授業 }` | 401／403／その id の授業がない 404／422 |

### 送る JSON

```json
{
  "code": "CS102",
  "name": "プログラミング応用",
  "teacher": null,
  "day": 1,
  "period": 2,
  "room": "J201",
  "credits": 2,
  "required": false
}
```

### 値の決まり（合わなければ 422）

| 項目 | 決まり | 422 のときの errors |
|---|---|---|
| `code` | 必須。英大文字2〜3文字と数字3つ。ほかの授業と重ならない（更新のときは自分自身とは重なってよい） | `errors.code` |
| `name` | 必須。100文字まで | `errors.name` |
| `teacher` | なくてよい（`null`）。50文字まで | `errors.teacher` |
| `day`・`period` | 必須の整数。曜日は1〜5、時限は1〜6 | `errors.day`・`errors.period` |
| `room` | 必須。教室の一覧（rooms）にある。同じ曜日・時限に同じ教室の授業がない | `errors.room` |
| `credits` | 必須の整数。1〜4 | `errors.credits` |
| `required` | 必須の真偽値 | `errors.required` |

### 422 の形

```json
{
  "message": "その授業コードはほかの授業で使われています",
  "errors": { "code": ["その授業コードはほかの授業で使われています"] }
}
```

### 決めたこと・あとで変えたこと

- 更新のときに授業コードが自分自身と重なるのはよい（W8 では、作っている途中で気づいて決めた）
- 学生から送られたら、値が決まりに合わなくても 403 を先に返す（W10）
